# 友情星域

这是一个送给李雨珊、陈可欣、陈馨妍、李秉轩的静态单页网站。

打开方式：

1. 保持 `friendship-site` 文件夹结构不变。
2. 双击 `index.html` 即可在浏览器中打开。
3. 如果要发给朋友，把整个 `friendship-site` 文件夹一起发送。

页面内容：

- 鬼灭之刃人物义勇、蜜璃、时透无一郎、玄弥原创同人风主视觉
- 四位朋友的 3D 星卡
- 今日友情剧本：随机生成队名、任务和友情结算报告
- 鬼灭人物切换区、今日呼吸法抽签、友情任务按钮
- 鬼杀队剧情盲盒：给可欣和馨妍的角色隐藏小剧场
- 李雨珊的跳舞舞台、24 弦互动古筝、搞笑夸夸机、随机舞步和舞台弹幕
- 李秉轩的超级飞侠风格大按钮小游戏：飞一站、抽积木、搭乐高高塔、打开神秘玩具盒
- 手机首屏使用轻量压缩图，鬼灭详情图延迟加载
- 星空粒子、星光按钮、古筝拨弦音效
